# Greet Skill

A simple, polished Claude skill that provides a warm, professional greeting and offers immediate assistance.

## Description
This skill ensures that Claude starts a conversation with a friendly tone. It is designed to be concise, personal (using the user's name when available), and helpful by prompting for a specific task.

## Installation

If you are using **Claude Code**, you can install this skill by pointing to your local directory or your GitHub repository:

```bash
/plugin add [https://github.com/jomel-rgb/greet](https://github.com/jomel-rgb/greet)
